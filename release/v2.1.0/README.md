# 非遗影像工坊 2.0｜AI 非遗短片导演台

## 项目简介

非遗影像工坊 2.0 是一款面向 AIGC 创作者、非遗爱好者与短视频创作者的 AI 辅助创作工具。用户只需输入非遗类型、创意主题与视觉风格，系统即可在数秒内生成一部包含完整创意故事、角色设定、场景设定、8 个分镜镜头、声音设计、文化表达检查与参赛说明的非遗短片完整方案。

## 产品定位

- **目标用户**：AIGC 比赛参赛者、非遗主题短视频创作者、文化传媒专业学生、对非遗感兴趣的普通用户
- **核心痛点**：
  1. 想拍非遗短片但缺乏系统的分镜与创意策划能力
  2. 参赛时需要完整的作品说明与技术文档，撰写耗时
  3. AI 视频生成需要大量提示词，反复调试成本高
  4. 非遗文化表达容易流于表面，缺少深度检查

## 核心功能

1. **AI 非遗短片方案生成**：输入非遗类型、创意主题、作品用途、视频时长、视觉风格，一键生成完整短片方案
2. **AI 导演台**：8 大模块长页面展示，左侧 sticky 导航，支持锚点跳转与滚动高亮同步
3. **分镜导演台**：8 个完整镜头，每个镜头包含画面描述、首帧提示词、尾帧提示词、视频生成提示词、AI 可生成性评分
4. **提示词一键复制**：支持单个提示词复制、全部提示词批量复制、参赛说明完整复制
5. **在线编辑**：支持实时编辑作品简介、镜头描述、提示词等内容，自动保存到 localStorage
6. **Markdown 导出**：一键导出完整项目 Markdown 文档，方便提交与分享
7. **我的项目**：自动持久化保存，支持重命名、复制、删除
8. **4 个完整案例**：内置傩戏、铜梁龙、蜀绣、木版年画四大非遗主题完整案例

## 技术栈

- **前端**：React 18 + TypeScript + Vite 6 + React Router v6
- **状态管理**：localStorage 本地持久化
- **UI 样式**：CSS 变量 + 自定义主题（深蓝黑底 + 金/青点缀）
- **构建工具**：Vite（支持 base: "./" 相对路径构建）

## 页面结构

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `/` | Hero 背景、功能介绍、4 个精选案例入口 |
| 开始创作 | `/create` | 表单填写、一键生成 |
| AI 导演台 | `/director/:projectId` | 8 大模块长页面、编辑、复制、导出 |
| 案例库 | `/cases` | 4 个完整案例卡片 |
| 我的项目 | `/projects` | 项目列表、重命名、复制、删除 |

## 本地运行

```bash
npm install
npm run dev
```

访问 http://localhost:5173

## 构建方法

```bash
npm run build
```

构建产物输出到 `dist/` 目录。由于设置了 `base: "./"`，可直接双击 `dist/index.html` 打开，或在解压目录运行：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 快速体验模式说明

当前版本内置「快速体验模式」，使用本地 mock 数据生成器模拟 AI 返回，无需连接真实 AI API，即可在数秒内体验完整创作流程。适合比赛 Demo 展示与功能体验。

## AI 模式说明

产品架构已预留真实 AI API 接入点（故事生成、提示词优化、文化检查等模块），后续版本可通过配置环境变量接入 Doubao/Seedream/Seedance 等 AI 服务。

## API Key 安全说明

- 所有 API Key 均通过环境变量（`.env`）管理
- 前端代码中绝不暴露任何 Key
- 需要后端代理转发时，由 Node.js/Express 中间层处理鉴权
