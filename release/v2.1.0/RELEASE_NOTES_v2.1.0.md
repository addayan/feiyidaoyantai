# V2.1.0 Release Notes — 非遗影像工坊

## 版本摘要

V2.1.0 是"非遗影像工坊"的首个真实 AI 生成版本。本版本将原有的 mock 快速体验模式升级为真实 AI 驱动，通过后端 Express 代理接入 DeepSeek / 火山方舟大模型，实现了完整的分镜方案 AI 生成、单模块重新生成、单镜头重新生成、镜头 AI 优化和提示词单独优化等核心能力。

## 新增功能

### 1. 真实 AI 文本生成
- 接入 DeepSeek / 火山方舟大模型（OpenAI 兼容 API）
- 后端 Express 代理层，API Key 仅存在于服务端
- 支持 120 秒超时控制
- 前端 AbortController 支持取消请求

### 2. AI 配置检测
- `GET /api/health` 返回模型配置状态
- 前端根据配置状态动态启用/禁用 AI 按钮
- 未配置时显示友好提示

### 3. 单模块重新生成
- 支持 7 种模块：故事、角色、场景、声音设计、文化表达检查、参赛说明、发布文案
- 仅更新目标模块，其他模块保持不变
- 失败时自动恢复旧内容

### 4. 单镜头重新生成
- 支持对 8 个镜头中的任意一个进行重新生成
- 自动考虑前后镜头衔接
- 重新计算可生成性评分
- 失败时自动恢复旧镜头

### 5. 镜头 AI 优化
- 支持 9 种优化方向：增强电影感、增强情绪表达、增强运镜、增强非遗文化表达、增强 AI 可生成性、简化提示词、适配 Seedream、适配 Seedance、自定义
- 优化后重新计算可生成性评分

### 6. 提示词单独优化
- 支持首帧提示词、尾帧提示词、视频提示词的单独优化
- 返回纯文本优化结果
- 不改变其他提示词字段

### 7. AI 操作自动保存
- 所有 AI 操作完成后自动保存到 localStorage
- 刷新页面后内容保留

### 8. 生成历史记录
- 记录每次 AI 操作的类型、目标和时间
- 存储在 `generationHistory` 字段中

### 9. 旧项目兼容迁移
- V2.0.1 项目无 `generationMeta` 和 `generationHistory` 字段
- 打开时自动兼容，不报错
- 迁移后可以进行 AI 操作

## 兼容性

- 向后兼容 V2.0.1 的所有项目数据
- 向前兼容：V2.1.0 生成的项目可在后续版本中打开
- 4 个内置案例保持不变

## 安装步骤

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（仅 AI 模式需要）
cp .env.example .env
# 编辑 .env 填入真实 API Key

# 3. 启动开发模式
npm run dev:all
# 访问 http://localhost:5173
```

## AI 配置

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `ARK_API_KEY` | API Key（必填） | - |
| `ARK_MODEL_ID` | 模型 ID | `deepseek-chat` |
| `ARK_BASE_URL` | API 基础 URL | `https://api.deepseek.com` |
| `ARK_TIMEOUT_MS` | 请求超时（毫秒） | `120000` |

### 支持的模型

- **DeepSeek Chat** (`deepseek-chat`): 推荐，性价比最高
- **火山方舟豆包** (通过 `https://ark.cn-beijing.volces.com/api/v3`)

## 已知限制

1. **Seedream 和 Seedance 尚未真实调用**：当前版本仅接入文本大模型，图像/视频生成 API 尚未集成
2. **AI 生成内容可能不完美**：AI 模型可能不严格遵循非遗类型、视觉风格等约束，建议人工审核
3. **单次生成耗时较长**：完整分镜方案生成约需 30-90 秒，取决于模型响应速度
4. **无并发 AI 请求**：前端同一时间只允许一个 AI 操作

## 从 V2.0.1 升级说明

1. V2.0.1 的所有项目数据自动兼容，无需手动迁移
2. 如需使用 AI 功能，需配置 `.env` 文件
3. V2.0.1 的 `v2.0.1_HTML.zip` 和 `v2.0.1_source.zip` 保持不变
